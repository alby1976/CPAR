# A Dummies Guide to Downloading the Clinic Template

1. Open [AHS_CPAR_Reconcilation.xlsm](AHS_CPAR_Reconcilation.xlsm) and use **Download raw file**.
2. Save it in approved clinic storage, keeping the .xlsm extension.
3. Follow README and Setup_Checklist inside Excel.
4. Confirm your report layout is supported and test reviewed VBA in a separate copy.

The blank template contains no real provider or patient records. It includes 42 M queries, VBA buttons, and a PCPCM guide. Receiving clinics must test Excel compilation and live refresh before routine use.

Never upload populated clinic workbooks or real patient reports to this public repository. Only the explicitly reviewed blank template is allowed through the ignore rules.
